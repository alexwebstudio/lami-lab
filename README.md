# LAMI LAB — сайт студии ламинирования ресниц и бровей (Караганда)

Next.js (App Router) + JavaScript, GSAP для анимаций, Lenis для плавного скролла.
CSS Modules, без UI-библиотек. Figma-макет — визуальная база: палитра, фирменные
скруглённые углы и типографика сохранены, масштаб и ритм адаптированы под веб.

## Запуск

```bash
npm install
npm run dev     # разработка
npm run build   # продакшн-сборка
npm run start   # запуск собранного проекта
```

Перед деплоем скопируйте `.env.example` в `.env.local` и укажите домен:

```bash
NEXT_PUBLIC_SITE_URL=https://ваш-домен.kz
```

Без этой переменной сайт работает, но canonical, Open Graph, `sitemap.xml`
и `robots.txt` будут ссылаться на `localhost`.

## Шрифты

Все три шрифта макета подключены оригиналами, без системных подмен:

| Шрифт | Где | Начертание | Источник |
|---|---|---|---|
| Kyiv\*Type Sans | **все заголовки** | Bold, `wght 700` | `public/fonts/KyivTypeSans-Variable.woff2` |
| Kyiv\*Type Sans | основной текст, описания | Regular, `wght 350` | тот же файл |
| Jura | навигация, кнопки, подписи, цифры | Medium, `wght 500` | `public/fonts/Jura-Variable.woff2` |
| Italiana | логотип в шапке, подвале и меню | Regular | `next/font/google` |

Локальные файлы собраны из переданных архивов и переведены в woff2.

### Ось контраста Kyiv\*Type Sans

У шрифта кроме веса есть ось **`CONT`** — контраст штриха, и именно она
задаёт характер: при `CONT 0` это нейтральный гротеск, почти неотличимый
от системного, при `CONT 1000` — фирменный контрастный рисунок с тонкими
и толстыми штрихами. Ось `MIDL` (вторая декоративная) зафиксирована в 0.

В проекте ось выведена в две переменные `globals.css`:

```css
--heading-cont: 1000;  /* заголовки, цены, крупные акценты */
--text-cont: 0;        /* основной текст и описания */
```

Так одна гарнитура даёт две разные роли: выразительные заголовки
и спокойный читаемый текст. Чтобы сделать заголовки мягче, уменьшите
`--heading-cont` до 500 — правка одной строки.

### Онлайн-запись: DKD или собственная форма

`DKD_URL` в `src/data/site.js` пока `null`. В этом состоянии кнопки записи
открывают собственную пошаговую форму с отправкой заявки в Telegram —
это рабочая механика, а не заглушка.

Как только придёт ссылка DKD, впишите её в `DKD_URL` — все кнопки
«Записаться онлайн» и «Записаться на процедуру» станут ссылками на DKD.
Править компоненты не нужно.

### Правовые страницы

`/privacy-policy` и `/personal-data` собраны на общем шаблоне `LegalPage`.
Тексты лежат в `src/data/legal.js` — сейчас там предварительная редакция
с пометкой на странице. Чтобы опубликовать финальный документ, замените
массив `sections` и уберите поле `notice`; вёрстку трогать не нужно.
Обе страницы уже стоят в подвале и в `sitemap.xml`.

### Онлайн-запись и Telegram

Все кнопки «Записаться онлайн» и «Записаться на процедуру» открывают одну
пошаговую форму (`BookingFlow`): процедура → желаемый результат → удобное
время → контакты и проверка. Из карточки процедуры услуга подставляется
сразу, и первый шаг пропускается.

Заявка уходит на `/api/booking`, оттуда — в Telegram. Чтобы включить отправку:

1. Создайте бота у @BotFather и получите токен.
2. Узнайте id чата, куда бот будет писать.
3. Впишите оба значения в `.env.local`:

```
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
```

`.env.local` уже в `.gitignore` и в репозиторий не попадёт.

Пока переменные пустые, форма **честно** сообщает, что отправка не подключена,
и предлагает телефон и WhatsApp. Имитации успешной отправки нет: при любой
ошибке пользователь видит сообщение, введённые данные сохраняются, отправку
можно повторить.

Формат сообщения в Telegram — процедура, пожелание, удобное время, имя,
телефон и комментарий. Пустые поля не отправляются.

### Подробные описания процедур

Тексты лежат в `services[].details` (`src/data/services.js`): подводка,
описание процедуры, «кому подходит», «какой эффект», «как проходит»
и «уход после процедуры». Тексты общие и без обещаний по срокам —
перед публикацией стоит вычитать их под свою практику.
Изображение в поп-апе берётся из того же поля `image`, что и карточка услуги.

### Фотографии

Все снимки, кроме hero, — **временные**, с Unsplash (свободная лицензия).
Полный список с источниками: `public/images/CREDITS.md`.
Замена — простой перезаписью файла с тем же именем в `public/images/`,
пути в коде трогать не нужно. Пропорции кадров:

- услуги — 4:5;
- крупный кадр работы — 4:5, деталь — 1:1, превью — 1:1;
- портрет в «Обо мне» — 4:5.

### Цифры в блоке «Обо мне»

Блок с цифрами (`довольных клиентов`, `обучений`, `лет опыта`) **временно
скрыт**: реальных значений нет, а выдумывать их нельзя. Разметка и данные
сохранены. Чтобы вернуть блок — в `src/data/about.js` поставьте
`showStats: true` и впишите настоящие числа вместо `[X]`.

### Галерея работ

Слайды меняются автоматически раз в 5 секунд. Таймер запускается, когда
секция появляется на экране (IntersectionObserver), останавливается при
уходе из неё и перезапускается после ручного переключения стрелками или
превью — параллельных таймеров не возникает.

### Отзывы

`src/data/reviews.js` — пустой массив. Пока отзывов нет, секция показывает
законченную редакционную композицию со ссылками на площадки, где отзывы
уже живут: 2ГИС и Instagram. Добавьте записи вида
`{ id, author, date, text }` — секция сама переключится на сетку карточек,
вёрстку править не нужно. Отзывы не выдуманы и не сгенерированы.

### Карта

Заказчик просил 2ГИС. Для встраиваемой карты 2ГИС нужна ссылка виджета из
карточки организации (2ГИС → карточка студии → «Поделиться» → «Виджет»).
Пока её нет, карта работает на Google Maps по реальному адресу студии —
координаты не выдумывались. Впишите ссылку в `GIS_MAP_EMBED`
(`src/data/site.js`) — карта переключится на 2ГИС без правок вёрстки.

## SEO

Сделано: title и description, Open Graph и Twitter-карточка с готовым превью,
canonical, `robots.txt`, `sitemap.xml`, favicon и apple-icon, микроразметка
Schema.org `BeautySalon` (название, телефон, адрес, соцсети, прайс услуг),
корректная иерархия заголовков (один H1, H2 на секцию, H3 на карточки),
осмысленные `alt` у всех изображений, семантические `section` с `aria-labelledby`,
`lang="ru"`, локальные формулировки под Караганду.

Ничего не выдумано: в тексты и разметку попали только реальные данные проекта —
услуги, цены, телефон, адрес и соцсети.

## Палитра

Цвета собраны вокруг ассоциаций с ламинированием — тон кожи, фарфор
и оттенок ресниц/бровей. Все токены в `globals.css`:

| Токен | Значение | Роль |
|---|---|---|
| `--porcelain` | `#f7f2ed` | основной фон |
| `--sand` | `#efe5db` | чередующаяся полоса секций |
| `--latte` | `#e0d1c4` | Hero, «Обо мне», подвал |
| `--espresso` | `#1e1613` | основной текст, тёмные кнопки |
| `--cocoa` | `#6e5d51` | вторичный текст |
| `--cocoa-soft` | `#756254` | мелкие подписи |
| `--cognac` | `#7a4f35` | акцент: CTA, цены, цифры, hover |

Все пары «фон + текст» проверены на контраст: минимум в системе — 4.7:1
(акцент на `--latte`), кнопки — от 7:1.

## Отличия от макета (осознанные)

- **Тёмные полосы между блоками** в макете — фон холста Figma между фреймами,
  а не элемент дизайна. Секции идут вплотную, ритм задан чередованием фонов
  (белый → песочный → бежевый).
- **Композиция стала просторнее**: увеличены вертикальные отступы секций,
  межстрочные интервалы и размеры заголовков; сетка выросла до 1240px.
- **Шапка стала липкой**: при прокрутке уменьшается, получает размытие,
  подсвечивает текущий раздел и показывает полосу прогресса чтения.
- **Блок «Работы» перестроен**: вместо статичной сетки — портфолио с крупным
  кадром, перекрывающей деталью, номером работы, счётчиком, стрелками,
  лентой превью, свайпом и стрелками клавиатуры.
- **Блок доверия** вместо мелких рамок из макета — три колонки с воздухом,
  крупными заголовками и читаемым текстом.
- **Карточка «Обо мне»** из макета была пустой белой плашкой — теперь это
  портрет мастера.
- **Надзаголовков нет.** Мелкие плашки над заголовками убраны — иерархию
  держит сам заголовок, набранный Kyiv\*Type Sans Bold.
- **Конверсионные точки.** В Hero под кнопками — короткая строка цен;
  в «Обо мне» блок «Как я работаю» заканчивается CTA; в контактах телефон
  вынесен крупным типографическим акцентом; в подвале — закрывающий призыв;
  на мобильных после Hero появляется липкая панель «Позвонить / Записаться».
- **Телефон в шапке.** В макете технический номер `+7 777 777 77 67`;
  на сайте везде используется единственный номер `778-713-82-82`.
- **Первый экран во всю высоту**: `min-height: 100svh` — на мобильных
  учитывается адресная строка браузера.
- **Подвал стал тёмным** — финальная секция визуально закрывает страницу.
- **«Политика конфиденциальности» и «Обработка персональных данных»** пока
  обычный текст, а не ссылки: страниц с документами нет.
